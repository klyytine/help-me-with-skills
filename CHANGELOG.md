# Changelog

## 1.0.0

First release.

- `help-skill`: matches a task to an installed skill and gives one verdict with reasons.
- Search for a new skill when none fits, with a vetting checklist and install steps.
- `skill_inventory.py`: reads and ranks skills from personal, project, plugin and account-synced
  folders, and from marketplaces and the plugin directory cache with `--available`.
- Installers for Windows, macOS and Linux.
- Plugin and marketplace manifests for installing through `claude plugin`.
